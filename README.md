# 🛍️ My Shop Inventory Management System

A beginner-friendly Python project for managing a clothing shop.

## 📦 Products

- Kurti
- Plazo
- Pant
- Top
- Lehenga

## 🚀 Features

1. Add Product
2. Show Products
3. Search Product
4. Update Stock
5. Delete Product
6. Inventory Value
7. Low Stock Alert
8. Generate Bill
9. Daily Sales
10. Exit
11. Sales History

## 🛠️ Technologies Used

- Python
- CSV
- VS Code
- Git & GitHub

## 📁 Data Storage

Product information is stored in:

`products.csv`

Sales information is stored in:

`sales.csv`
