# Shop Inventory Management System — Phase 2

## Overview

This is the intermediate version of my Shop Inventory Management System built using Python and SQLite.

Phase 2 upgrades the beginner CSV-based system to a database-based system.

## Technologies

- Python
- SQLite
- SQL
- VS Code
- Git & GitHub

## Database

Database: SQLite

Database file:
- shop.db

Main table:
- products
- sales

## Features

1. Add Product
2. Show Products
3. Search Product
4. Update Stock
5. Delete Product
6. Inventory Value
7. Low Stock Alert
8. Generate Bill
9. Save Sales
10. Update Stock Automatically After Sale

- Create database and tables
- INSERT data

- SQL WHERE condition
- Python with SQLite
- Database CRUD operations
- Sales transaction handling
